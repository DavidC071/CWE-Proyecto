Fuente del proyecto — Poppins

La app está configurada para usar la fuente **Poppins** 

Cómo agregarla (una sola vez)

1. Descarga Poppins gratis desde Google Fonts:
    https://fonts.google.com/specimen/Poppins
   (botón **"Get font"** → **"Download all"**). Se baja un .zip.

2. Descomprime el .zip y copia **estos 4 archivos** a esta carpeta
   (`assets/fonts/`), con el nombre EXACTO:
   - `Poppins-Regular.ttf`
   - `Poppins-Medium.ttf`
   - `Poppins-SemiBold.ttf`
   - `Poppins-Bold.ttf`

3. En la terminal del proyecto:
   ```
   flutter pub get
   flutter run
   ```

¡Listo! Toda la app usará Poppins automáticamente.
